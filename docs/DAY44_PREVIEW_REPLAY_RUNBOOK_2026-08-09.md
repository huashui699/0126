# Day 44 Preview 回放与回滚预演手册

> 准备日期：2026-08-09  
> 当前状态：准备已启动；连续 7 天正式回放尚未开始  
> 环境边界：仅 Preview/隔离数据；未经单独授权不得操作生产

## 1. 正式计时的启动门禁

以下条件必须同时满足，才可把某一天记为 Day 44 的第 1 天：

- Day 41 的 300 条双人标注、裁决和系统预测完成，自动报告显示全部质量门禁通过。
- Day 42 的安全 migration 已应用到 Preview，pgTAP、绿色硬门禁和来源停用回滚式烟测通过。
- Day 43 的高数据量、移动端、无障碍、4G 性能、错误恢复和后台安全矩阵完成，发布预算已由团队确认。
- Preview 中存在可合法处理、可回滚且与生产隔离的 7 天数据；来源授权状态和 `is_simulated` 标记真实准确。
- 已记录 Preview 数据库恢复点或已验证的逻辑备份，并确认值班人、停止条件和证据存放位置。

未满足上述条件时，可以执行静态检查、合成数据演练和手册评审，但不得把等待时间计入“连续运行 7 天”。

## 2. 每日回放记录

连续 7 天每天固定在同一时间窗执行并保留以下证据：

| 字段 | 记录内容 |
|---|---|
| 日期/时区 | 上海时间开始、结束时间 |
| 部署 | Preview URL、deployment ID、Git SHA |
| 数据 | 来源数、任务数、raw items、新增新闻、去重数、失败数 |
| 质量 | 绿色/蓝色/红色数量、人工抽检数、错误标记数 |
| 性能 | 任务 P50/P95、API 5xx、页面 LCP/INP/CLS |
| 恢复 | 重试次数、人工处置、恢复时间、是否触发停止条件 |
| 审批 | 执行人、复核人、证据链接 |

验收口径：核心来源任务成功率至少 99%，重复运行不产生重复记录；任何模拟数据必须持续保留模拟标记，且不能升级为绿色。

## 3. 四项必做演练

### 3.1 任务失败与恢复

1. 在隔离的 Preview 来源或合成 Adapter 上制造一次可识别的超时/5xx，不修改生产来源。
2. 记录失败运行的结构化错误、重试次数和其他来源是否继续执行。
3. 恢复配置后重跑相同批次，验证幂等键阻止重复写入。
4. 保存失败前后 `ingestion_runs`、`raw_items` 和页面状态证据。

通过条件：单来源失败不拖垮其他任务；错误不泄露密钥或数据库细节；恢复后无重复记录。

### 3.2 来源停用

1. 选择专用 Preview 来源，记录当前启用状态及关联新闻的可信度。
2. 停用来源，确认新任务不再调度，关联绿色内容自动降级且历史仍可读取。
3. 验证客户端不会继续把停用来源展示为绿色确认。
4. 回滚演练数据，保存审计记录；不要删除历史以伪造恢复。

通过条件：停用即时阻断采集并撤销不再成立的绿色状态，恢复操作有完整审计链。

### 3.3 数据库迁移/恢复

1. 核对 Preview migration 历史和恢复点，再执行 `supabase db push --dry-run`。
2. 在隔离数据库验证备份可恢复；记录文件哈希、项目 ref 和恢复耗时。
3. 对候选 migration 先执行测试，再执行 Preview migration 与 pgTAP。
4. 失败时优先停止发布并使用 forward-fix；已有业务数据时禁止直接 drop。

详细分级策略沿用 [数据库运行手册](./DATABASE_RUNBOOK.md)。

### 3.4 Vercel 回滚

1. 记录当前稳定 Preview deployment ID，并使用 `vercel inspect <deployment>` 保存状态。
2. 对候选 Preview 完成构建、E2E 和 API 烟测，记录候选 deployment ID。
3. 在隔离域名验证 alias/promote 流程后，演练 `vercel rollback <stable-deployment-id>`。
4. 回滚后重新检查首页、详情、标注台、管理 API 拒绝路径和运行日志。

通过条件：回滚目标明确、无重新构建歧义；回滚后关键路径恢复，错误日志没有持续新增。Vercel token、组织 ID 和项目 ID 只存放在受控环境变量中。

## 4. 立即停止条件

出现以下任一情况，终止当天回放且不得用次日成功掩盖：

- 模拟/未批准来源被标为绿色或进入生产采集。
- 管理 API 未授权可写、service role key 泄露到客户端，或 RLS 隔离失效。
- 数据重复、丢失或迁移状态不明，且没有已验证恢复点。
- 持续 5xx、任务成功率低于 99%，或告警无法送达负责人。
- 回滚目标、执行人或证据缺失。
